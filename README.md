## Dependencies for hyprland
- kitty: terminal
- eza: better ls
- hyprpaper: for the wallpapers
- waybar: for the bar
- dunst: for the ...
- wl-clipboard: for copying things
- cliphist: to see clipboard changes
- ranger: as file manager
- python-pillow:to show images in ranger
- pipewire, pipewire-jack, pipewire-alsa, pipewire-pulse, qjackctl, wiremix: for audio
This are only some of them, I don't find the time to put them here
- tmux, tpm: for workflow. tpm is installed via gir [repo](https://github.com/tmux-plugins/tpm)
- vim, nvim: for working on the text files
Note: for the icons you need something like nerd fonts or font awesome
